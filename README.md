# 深宮秘檔・侍寢錄 PWA GitHub Pages 版

## 上傳方式

把本資料夾內所有檔案上傳到 GitHub repository 根目錄：

- index.html
- manifest.json
- service-worker.js
- icon-192.png
- icon-512.png
- icon-maskable-512.png
- README.md

GitHub Pages 開啟後，手機用 Safari / Chrome 打開 GitHub Pages 網址，再加入主畫面。

## 資料隱私

本版本為手機單機匯入版：

- 不連動伺服器 API
- 不自動上傳 JSON 名冊
- 不使用 localStorage 儲存名冊
- 匯入資料只存在當次瀏覽器頁面記憶體
- 重新整理後需要重新匯入

請不要把你的名冊 JSON 上傳到 GitHub repository。
